**Browser demo** of the [Quaternion Vortex Persistent Identity Conduit (QVPIC)](https://github.com/kinaar8340/qvpic) — geometric deep-learning memory for drift-resistant persistent identity.

No install required — use the **App** tab above.

> **Simulation demo** — bake → recall → drift benchmark on generic demo facts. Full agent chat with local LLM runs via `python scripts/main.py` on your machine.

---

## What you can run

| Action | Output |
|--------|--------|
| **Run benchmark** | Bake demo facts into RingConeChain, recall cosine table, topology stats, drift protection factor |
| **Run query recall** | Top-k cube recall for a custom query string |
| **Braided lattice** | Optional PNG from `render_braided_lattice_style()` |

Tune bake steps, read bandwidth, drift samples, and max facts. Default path is **RubikConeConduit**; enable **VQCEnhanced** for the experimental helical variant.

## Matrix control panel

Same UX family as [orbital-braille-vqc](https://huggingface.co/spaces/kinaar111/orbital-braille-vqc) and [hopf-flux-bubble](https://huggingface.co/spaces/kinaar111/hopf-flux-bubble):

- **Selection menu** — D-pad navigable TUI
- **Prog keys 02–05** — Status, Bake & Recall, Drift & Topology, Help
- **01 Home** — return to menu
